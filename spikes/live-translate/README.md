# Live translation — disposable Rust spike

**Увага:** ця утиліта передає звук явно вибраного процесу Google. Не мікрофон. Потік і ключ не записуються на диск. Без Tauri UI: це погоджений експеримент, не продуктовий код. Майбутній продукт лишається Rust + Tauri для macOS/Windows/Linux.

## Запуск

macOS 14.2+, Rust, Xcode. Аудіодозвіл macOS має бути наданий користувачем. Поточний input має бути Float32 stereo 48 kHz, output — Float32; інші формати відхиляються, а не обробляються навмання.

Із кореня репозиторію:

```sh
cargo build --manifest-path spikes/live-translate/Cargo.toml
# Увімкни відео зі звуком та знайди його активний аудіо-PID:
cargo run --manifest-path spikes/macos-process-audio/Cargo.toml -- list
cargo run --manifest-path spikes/live-translate/Cargo.toml -- AUDIO_PID
# Тихий оригінал (15%) + переклад (70%):
cargo run --manifest-path spikes/live-translate/Cargo.toml -- AUDIO_PID --original-volume 0.15
```

Ключ: `GEMINI_API_KEY` у середовищі цього процесу або прихований ввід у терміналі. Не передавати ключ аргументом командного рядка. Не додавати його в код/Git/чат. Платний білінг утиліта не вмикає і тариф проєкту не визначає.

Сесія: `gemini-3.5-live-translate-preview`, мова `uk`, `echoTargetLanguage=false`. JSON у відповідях WebSocket обробляється як text або binary.

## Аудіопотік

1. Приватний Core Audio Process Tap лише для вибраного PID, `MutedWhenTapped`.
2. Stereo → mono → FIR low-pass 63 taps → decimation 48 → 16 kHz.
3. PCM16 LE, 100 ms chunks → офіційний Gemini Live WebSocket.
4. PCM16 mono 24 kHz → bounded queue → лінійна інтерполяція до частоти output → CPAL playback (gain 0.7).
5. Окрема локальна черга захопленого оригіналу 48 kHz → той самий output callback зі своїм gain (`--original-volume`, 0..1, типово 0). Оригінал звучить і до появи перекладу. Початковий prebuffer: оригінал ~43 ms, переклад 100 ms; це не синхронізація смислу — оригінал випереджає переклад. Обидва потоки підсумовуються з обмеженням піків до [-1, 1]. Системний вихід джерела вимкнений, чути його локальну копію; вхід до Gemini не містить цієї суміші.

Realtime callbacks не виконують мережевих/дискових операцій, не алокують і використовують SPSC ring buffers. Capture buffer — 1 секунда; playback buffer — 5 секунд. Переповнення припиняє тест замість неявного пропуску мовлення. Порожній output buffer дає тишу.

20 секунд від старту захоплення — цільовий ліміт тесту. Наприкінці переклад зупиняється без догравання хвоста, tap видаляється й оригінал відновлюється. Час блокувального network write може додати до ліміту до timeout; DNS/TCP/TLS setup не має загального deadline всередині утиліти. Ctrl+C виставляє stop flag; не гарантує миттєвого виходу з блокувального setup/read/write. RAII виконує штатне очищення на поверненні помилки. Аварійне завершення, Bluetooth, зміни пристроїв та тривала робота ще не перевірені.

Для експерименту налаштування tap продубльовано з першого spike; не переносити таке дублювання в продукт. Usage description Info.plist береться з `../macos-process-audio/Info.plist`.

## Перевірено на цьому Mac

- `cargo test`: 3 тести пройшли (48→16 kHz count/DC, PCM16 decode/queue limits, підмішування оригіналу без перекладу та обмеження піків).
- `cargo clippy -- -D warnings`: без зауважень.
- Наскрізний запуск Chrome завершився з кодом 0.
- Передано **19.9 с** аудіо, отримано **15.2 с** перекладеного аудіо, playback callback спожив приблизно **15.2 с**.
- Перший output chunk прийшов через **4.58 с від старту захоплення**. Це не вимірювання смислового відставання і не гарантія наступних запусків.
- Спостережена черга playback після старту: приблизно **0.31–0.59 с** у періодичних вимірах; наприкінці 0.
- Користувач підтвердив, що чує переклад; окремий повтор на російськомовному відео теж успішний.
- Останній тест зі змішуванням: original gain 0.15, translation gain 0.7, код завершення 0; передано 19.9 с, отримано 17.0 с, перше аудіо на 3.42 с, черга в періодичних вимірах ~0.17–0.42 с. Суб'єктивний баланс і чутність тихого оригіналу ще має підтвердити користувач.

Різниця тривалостей input/output сама по собі не означає пропущений зміст: є стартова затримка, паузи, інша довжина перекладу та навмисне відсікання хвоста тесту. Повноту перекладу цим запуском не виміряно.

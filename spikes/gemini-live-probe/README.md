# Gemini Live Translation — connection probe (Rust)

Одноразовий експеримент, не продукт. Відкриває офіційний Gemini Live WebSocket, надсилає setup для `gemini-3.5-live-translate-preview` з мовою `uk`, чекає `setupComplete` і закриває сесію. Не захоплює й не передає аудіо, не змінює білінг. Наявність безкоштовної квоти не визначає.

З кореня проєкту:

```sh
cargo run --manifest-path spikes/gemini-live-probe/Cargo.toml
```

Ключ береться з `GEMINI_API_KEY`, якщо змінну встановлено в тому самому середовищі. Інакше запитується прихований ввід у терміналі. Встав ключ і натисни Enter: символи не показуються, ключ не зберігається на диску. Не вставляй ключ у командний рядок, Git чи чат.

`PASS` означає лише підтверджене створення сесії, не перевірку перекладу або доступного обсягу безкоштовного використання. URL та помилки встановлення з'єднання приховані, щоб не вивести ключ; для помилок сесії повідомляються код та діагностика із заміною точного значення ключа на `[REDACTED]`. Встановлені таймаути читання/запису, але DNS/TCP/TLS connection establishment окремого загального deadline не має. У разі зависання можна завершити Ctrl+C.

Для повного тесту ще потрібні передавання PCM 16 kHz mono і відтворення отриманого PCM 24 kHz mono. Фактична перевірка на Mac: ключ прийнято, metadata endpoint підтвердив `bidiGenerateContent` для моделі, Live WebSocket повернув `setupComplete` із мовою `uk`; утиліта завершилася з `PASS` та кодом 0 без надсилання аудіо. Під час перевірки виявлено, що відповідь JSON може надходити бінарним WebSocket-повідомленням; утиліта обробляє і text, і binary. Білінг і обсяг безкоштовної квоти цим не перевірені.

# macOS process audio — throwaway feasibility spike

Це **експеримент на Rust**, не продукт і не затверджена архітектура. Стек майбутнього продукту: Rust + Tauri. Тут немає UI, Tauri, Gemini, мікрофона чи мережевих запитів під час захоплення. Cargo завантажує залежності під час збірки.

## Запуск

Потрібні macOS 14.2+, Xcode Command Line Tools та Rust. Із цієї директорії:

```sh
cargo build
cargo run -- list
cargo run -- capture PID 5
cargo run -- capture PID 5 --mute-original
# Автоматичний тест на власному тихому тоні, без захоплення інших програм:
python3 test-tone.py
```

`PID` — саме аудіопроцес із `list`, не обов'язково головний процес програми. Тривалість обмежена 1–30 секундами. Для ручного тесту запусти звук джерела до отримання списку. Chrome/Discord можуть мати декілька допоміжних процесів; автоматичне групування ще не реалізоване.

macOS може попросити дозвіл на захоплення аудіо. Дозвіл надає користувач; утиліта не обходить TCC і не змінює налаштувань приватності. Usage description вбудовано в executable через Info.plist. Відмова може проявлятися як тиша, а не помилка створення tap.

## Що робить

- Знаходить Core Audio process objects для явно вибраного PID.
- Створює приватний stereo process tap та тимчасовий приватний aggregate device.
- Для `--mute-original` використовує `CATapMutedWhenTapped`: за контрактом Apple оригінал не йде на аудіовихід, поки tap читається.
- Рахує callbacks, кількість Float32-семплів, нетихі семпли та пікову амплітуду. Не записує захоплений звук на диск.
- При штатному завершенні/поверненні помилки зупиняє IO, видаляє callback, aggregate device і tap. Не змінює default device або гучність системи.
- Тестовий скрипт створює тимчасовий WAV із синтетичним тоном, запускає власний `afplay`, завершує його та видаляє WAV після тесту.

## Фактичний результат на цьому Mac

macOS 26.5 / arm64 / Apple A18 Pro. Перша перевірка власного `afplay`, 48 kHz stereo:

| Режим, 3 секунди | Callbacks | Семпли | Нетихі семпли | Peak |
|---|---:|---:|---:|---:|
| Звичайний | 280 | 286720 | 286666 | 0.02992 |
| `--mute-original` | 281 | 287744 | 284514 | 0.02992 |

**Доведено:** отримуємо реальні нетихі семпли вибраного процесу в обох режимах, зокрема коли tap налаштований на вимкнення оригіналу.

**Не доведено цим тестом:** фізична тиша динаміків, ізоляція від другого одночасного джерела, відновлення чутного оригіналу після завершення, поведінка при аварійному завершенні, браузери/DRM, Bluetooth, зміна пристрою, довга сесія, затримка перекладу. Лічильники не є акустичним вимірюванням. Додаткові запуски змінюють числові результати залежно від планування IO.

Перед продуктовим використанням потрібні обробка життєвого циклу процесів, явна політика дозволів, контроль переповнення, перевірка відновлення звуку та безпечна інтеграція в Tauri. Backend цього експерименту лише macOS; вимога Windows/Linux лишається незмінною.

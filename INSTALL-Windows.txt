Live Translator для Windows 11 x64

1. Розпакуйте ZIP-архів у зручну папку.
2. Запустіть live-translator.exe.
3. Додайте ключ Google AI Studio у налаштуваннях, виберіть програму зі звуком і почніть переклад.

Для роботи потрібен Microsoft Edge WebView2 Runtime. Якщо його немає, завантажте та встановіть його з https://developer.microsoft.com/microsoft-edge/webview2/.

Windows може показати попередження під час першого запуску. Переконайтеся, що завантажили архів з офіційної сторінки проєкту, перш ніж відкривати програму.

Гучність оригіналу змінюється у програмі-джерелі або системному мікшері, гучність перекладу — у Live Translator.

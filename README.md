# Live Translator

Перекладає та озвучує звук вибраної програми. Дивіться відео, стрими й слухайте розмови своєю мовою.

**[Завантажити для Windows](https://github.com/kvxshenyjbetxn/live.translator/releases/latest)** · Windows 11 x64, потрібен Microsoft Edge WebView2 Runtime

**[Завантажити для macOS](https://github.com/kvxshenyjbetxn/live.translator/releases/tag/v0.9.0)** · попередня версія 0.9.0 для macOS 14.2+ і Mac із M1 або новішим чипом Apple. Нова версія доступна для Windows.

## Початок роботи

1. На Windows завантажте ZIP-архів, розпакуйте його й запустіть **live-translator.exe**. Якщо потрібен WebView2 Runtime, встановіть його з [сайту Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/). На macOS скористайтеся інструкцією в архіві версії 0.9.0.
2. Додайте ключ із [Google AI Studio](https://aistudio.google.com/apikey) у налаштуваннях.
3. Виберіть програму зі звуком, мову й натисніть **«Почати переклад»**. На macOS дозвольте запис системного аудіо, якщо система запитає; мікрофон не потрібен.

На Windows гучність оригіналу змінюється у самій програмі або системному мікшері, а гучність перекладу — у Live Translator.

## Важливо

Потрібні інтернет і доступ до Google Gemini; безкоштовне використання має ліміти. Переклад звучить із невеликим відставанням.

Після запуску перекладу аудіо передається Google. Безкоштовний сервіс може використовувати його для вдосконалення продуктів — враховуйте це для приватних розмов. [Умови сервісу](https://ai.google.dev/gemini-api/terms).

Ключ зберігається на вашому комп’ютері без шифрування. Не передавайте його іншим.

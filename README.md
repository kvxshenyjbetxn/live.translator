# Live Translator

Перекладає та озвучує звук вибраної програми через Google Gemini. Підходить для відео, стримів і розмов; переклад звучить із невеликим відставанням.

**[Завантажити для macOS](https://github.com/kvxshenyjbetxn/live.translator/releases/latest)** · macOS 14.2 або новіша, Apple Silicon (M1 і новіші)

## Можливості

- Переклад українською, англійською, польською та німецькою.
- Вхідний і вихідний текст наживо: оригінал і переклад у двох стовпцях.
- Окрема гучність оригіналу й перекладу: оригінал можна зробити тихішим або вимкнути.
- Обрані програми, керування з рядка меню та гаряча клавіша.
- Український та англійський інтерфейс, теми й автоматичне збереження налаштувань.

## Встановлення

1. Завантажте ZIP за посиланням вище, розпакуйте його та перенесіть **Live Translator.app** до папки **«Програми»**. Перед оновленням закрийте попередню версію.
2. Відкрийте програму. Якщо macOS блокує запуск, після спроби відкриття перейдіть у **Системні параметри → Приватність і безпека → Відкрити попри це**.

Якщо macOS повідомляє про «пошкодження» або не пропонує дозволити запуск, скористайтеся інструкцією `INSTALL-macOS.txt` із ZIP. Не вимикайте захист macOS глобально й не ігноруйте попереджень про шкідливе ПЗ.

## Як користуватися

1. Отримайте ключ у [Google AI Studio](https://aistudio.google.com/apikey), додайте його в налаштуваннях і натисніть **«Перевірити з’єднання»**.
2. Увімкніть звук у потрібній програмі, оновіть список ліворуч і виберіть її.
3. Оберіть мову й натисніть **«Почати переклад»**. За запитом дозвольте запис системного аудіо; мікрофон не потрібен.
4. Налаштуйте гучність і натисніть **«Зупинити»**, коли завершите.

## Важливо

Тексти залишаються лише в пам’яті після зупинки чи помилки та очищуються з новим запуском або закриттям програми.

Аудіо вибраної програми передається Google лише після запуску перекладу. На безкоштовному рівні Google може використовувати дані для вдосконалення своїх продуктів; ознайомтеся з [умовами Gemini API](https://ai.google.dev/gemini-api/terms) перед перекладом приватних розмов.

Для роботи потрібні інтернет і доступ до Gemini. Безкоштовний рівень має квоти, а успішна перевірка з’єднання не гарантує їхнього залишку. Ключ платного проєкту використовує його тариф.

**Ключ зберігається на вашому комп’ютері відкритим текстом, без шифрування.** Не передавайте іншим ключ або файл налаштувань.

# Live Translator

Перекладає та озвучує звук вибраної програми. Дивіться відео, стрими й слухайте розмови своєю мовою.

**[Завантажити для macOS](https://github.com/kvxshenyjbetxn/live.translator/releases/latest)** · macOS 14.2+, Mac із M1 або новішим чипом Apple

## Можливості

- Переклад українською, англійською, польською та німецькою.
- Оригінальний текст і переклад поруч на вкладці «Тексти».
- Окрема гучність оригіналу й перекладу.
- Обрані програми, гаряча клавіша, теми та український інтерфейс.

## Початок роботи

1. Завантажте архів, розпакуйте й перенесіть **Live Translator.app** до папки **«Програми»**. Допомога з першим відкриттям — в інструкції всередині архіву.
2. Додайте ключ із [Google AI Studio](https://aistudio.google.com/apikey) у налаштуваннях.
3. Виберіть програму зі звуком, мову й натисніть **«Почати переклад»**. Дозвольте запис системного аудіо, якщо macOS запитає; мікрофон не потрібен.

## Важливо

Потрібні інтернет і доступ до Google Gemini; безкоштовне використання має ліміти. Переклад звучить із невеликим відставанням.

Після запуску перекладу аудіо передається Google. Безкоштовний сервіс може використовувати його для вдосконалення продуктів — враховуйте це для приватних розмов. [Умови сервісу](https://ai.google.dev/gemini-api/terms).

Ключ зберігається на вашому Mac без шифрування. Не передавайте його іншим.
